# COMMDIS3

SLP 3 Study Repository — Comm Dis 3

## Setup

1. Open https://thetripleb.github.io/COMMDIS3/ in your browser
2. Go to **Manage Data > GitHub Sync**
3. Enter your GitHub PAT (Contents: read/write on this repo)
4. Click **Save & Connect**

Data is stored in `commdis3_data.json` and syncs automatically across devices.
